# Verifica.ai Identidade
Console em português para administradores e desenvolvedores testarem autenticação facial 1:1 com consentimento. Uma referência pertence a um identificador informado; não há busca 1:N. API em Python/FastAPI, OpenCV SFace e YuNet para inferência local. O serviço próprio experimental usa desafios de movimentos e detecção opcional de objetos. Não é PAD validado e exige revisão, sem aprovação automática. O caso de uso inicial é validação para ponto, com possibilidade de autenticação e acesso. O console hospedado é demonstrativo, com dados sintéticos e conexão opcional ao backend separado. Sem alegações de precisão, certificação ou capacidade medidas.
